## Association inventory and harmonization

Primary bounded laptop procedure: conservative gene-body SNP-min Bonferroni tests, `p_gene = min(1, m * min(p_snp))`, where m is the number of valid tested SNPs overlapping each GENCODE v19 autosomal protein-coding gene. This is a standard union-bound association test valid under arbitrary LD, not MAGMA, a causal assignment, or an LD-estimated effective-test correction. Use all eligible SNPs, not just genome-wide-significant SNPs. Test all covered protein-coding genes; report Bonferroni across tested genes as a conventional association multiplicity adjustment, **not a dark-gene/cognitive enhancement success criterion**. Keep all genes and raw values in the inventory, including unscored genes. Gene-body windows are zero; this choice avoids tuning windows to obtain unfamiliar hits but misses distal regulation. If variants/positions disagree with the source build, stop that mapping rather than infer a new build.

This conservative test is a planned departure from a full MAGMA run: MAGMA is optional in the synthesis; its toolchain/reference is not present in this checkout. The union bound sacrifices power but does not pretend SNPs are independent. Actual LD follow-up is still required. No nearest-gene assignment. Coordinates are 1-based inclusive, autosomes only. Validate alleles/beta/SE/p/frequency and document exclusions. GWAS p-values drive association; LD allele orientation drives comparisons and QTL effect harmonization. Ambiguous A/T and C/G orientation, duplicate markers, missing reference variants and mapping disagreements are recorded, not silently flipped.

## Loci and alternatives

Rank loci by direct-cognition lead p, independent of knownness. Start from source genome-wide threshold 5e-8. Define conservative physical candidate regions by union of +/-500 kb around significant SNPs, merging overlapping intervals; these are analysis regions, **not independent causal loci**. Report LD between lead and available significant variants in the EUR reference, reference coverage and allele alignment. Inspect the first three p-ranked regions as a bounded pilot, not an arbitrary success requirement; retain all genome-wide regions in the inventory. Preserve every overlapping gene in each region as a competitor, including genes without significant body tests. Multiple correlated gene-body associations cannot discriminate genes. Reference missingness and physical-region boundaries can obscure secondary signals.

For pilot regions, compare gene-body variant positions and lead LD, and query compatible adult-brain cis-QTL summaries for competing genes where available. If full local GWAS/QTL summaries can be aligned, use single-causal-variant approximate-Bayes-factor coloc; report H0–H4 with prior sensitivity p12=1e-6,1e-5,1e-4 (p1=p2=1e-4), assumptions and multiple-signal limitations. Do not run coloc on significant-only QTL pairs. Missing compatible full data yields **unavailable**, not H4=0. Without sufficient shared-signal evidence or another discriminating mapping, every gene remains unresolved. Adult expression alone cannot assign a locus or causal timing.

## Bias checks and context

Report gene length, SNP count/density, annotation/mapping coverage and HPA adult brain expression availability. Use genome-wide covered-gene comparisons matched on log gene length and SNP density (fixed quantile strata), with expression availability separately, to inspect whether apparent association/knownness patterns survive comparability. Report continuous knownness, missingness, unmatched strata and study-wide ascertainment; these descriptive comparisons are not another independent confirmation or a gate tuned after results. Audit alternative annotation boundaries and genes overlapping the same signals. Existing scores derived from Lee/Savage are never counted as independent experiments.

Check publicly documented perturbation-data coverage for pilot genes, explicitly separating neuronal readouts, developmental organism phenotypes and generic cell-fitness screens. Missing coverage is not a negative phenotype. Lifelong genetic association can reflect development, adult function, health, indirect effects or multiple tissues. Keep all these interpretations visible.

## Fail / continue and outputs

Synthesis rule: fail the shortlist if every apparently unexplained hit depends on nearest-gene assignment, annotation artifacts, inconsistent identifiers or reused data treated as independent confirmation. An unresolved neighbouring-gene comparison stays unresolved and cannot be won by the lowest knownness. Continue only where assignment is credible under alternatives and adult biological context yields a falsifiable functional question; no arbitrary convergent-score count, percentile cutoff or effect size defines success.

Commit reproducible scripts, small TSV inventories/alternatives/bias/access tables, README and a short VERDICT separating reproduced facts, new associations and open causal questions. Large inputs/reference and execution logs stay ignored under `experiments/route2/data/`. Record inaccessible/partial scopes and all departures. A failed or blocked shortlist is a valid dossier: say exactly where resolution ends; do not enlarge/tune it. No molecules, dosing, interventions, enhancement claim, beneficial manipulation direction or acute reversibility. Local CPU first; no Modal/GPU anticipated.
