# Route 2: cognition-locus alternatives

**The bounded follow-up did not resolve a poorly understood causal cognition gene.** It produced an association inventory, credible competing hypotheses and a specific resolution failure, not an intervention target list. See [VERDICT.md](VERDICT.md).

The initial choices and later diagnostic additions are recorded in [PLAN.md](PLAN.md). No knownness value selected a SNP, gene, region, association threshold or genomic rank.

## Reproduce locally

From the repository root:

```sh
uv sync --frozen
uv run --frozen --with-requirements experiments/route2/requirements.txt \
  python experiments/route2/run.py
```

This reuses `scripts/fetch.py` and the committed data layer; it does not rebuild the initial common/rare join. The stored run used Python 3.13.15. Core packages httpx 0.28.1, openpyxl 3.1.5 and pypdf 6.19.0 are locked in `uv.lock`; the additional scientific packages are pinned in `requirements.txt`. No MAGMA binary, R, PLINK executable, cloud account, Modal or GPU is used. The public PLINK reference is decoded directly with NumPy.

Large inputs, extracted reference genotypes and the selected QTL cache remain ignored in `data/` and `experiments/route2/data/`. A fresh run needs roughly 4.8 GB of input/extracted-reference space, not a whole atlas. Runtime logs are not committed. Existing downloaded bytes are hash-checked and retain their original observations; a cached run is not a new network check. Provenance/access files contain observation metadata, so fresh downloads need not reproduce their timestamps or gzip envelopes bit-for-bit. Scientific tables are regenerated by the scripts, with no manual table editing.

HGNC uses the changing complete-set URL. The LD archive is checked against the fetch manifest. BED/BIM/FAM files are extracted only when absent; existing extracts are reused. The context step verifies HPA and guide-file hashes, then reads the three VEP JSON responses without a separate VEP pin check. The original VEP raw-byte pins are retained, not refreshed or converted to canonical JSON hashes.

Fetching rewrites the core and Route 2 manifests. Changed responses carry their expected prior hash. A fresh source response may block a required input check. There is no separate runtime-observation manifest.

## Procedure and actual coverage

1. **Association:** stream all **10,098,325** original Lee cognitive-performance rows; all pass the stated autosomal SNV/numeric/unique-marker checks. For every overlapping GENCODE v19 protein-coding body, calculate `p_gene = min(1, SNP_count * min_SNP_p)`. This union-bound test is conservative under arbitrary LD; it does **not** assume independent SNPs or estimate an effective SNP count. Test **18,913** covered genes out of **19,430** autosomal protein-coding genes. Bonferroni over tested genes gives **406** associations at conventional familywise 0.05. These numbers are association results, not success criteria or causal gene counts. Distal regulation and non-protein-coding genes are outside this gene test; noncoding locus alternatives are retained and labelled **untested**, not negative.
2. **Regions:** **13,714** source-threshold SNPs (`p < 5e-8`) yield **160** merged +/-500 kb physical regions. They are not 160 independent causal loci. Follow the first **three** regions ranked solely by CP lead p, as planned. They contain **199** annotated alternatives, including **87 / 8 / 9** protein-coding genes in R001/R002/R003. Preserve the other regions without pretending to have followed them all.
3. **LD:** 1000 Genomes phase 3 EUR, **503** people, source release 20130502, CNCR conversion downloaded 8 June 2016 and reference updated 19 September 2018. Of **18,755** pilot GWAS variants, **15,987** are allele/position aligned; **2,672** palindromic variants are left unoriented and **96** are absent. All three region leads are covered; no matched-marker coordinate or nonpalindromic allele mismatch was observed. Calculate mean-imputed dosage correlations with the region lead, not a causal credible set. Frequency differences are retained in `ld-harmonization.tsv`; no invented frequency cutoff selects hits. Missing LD is `NA`, not zero.
4. **Adult QTL:** anonymous indexed queries retrieve **310,264** nominal records from eQTL Catalogue **QTD000176**, reprocessed GTEx v8 frontal cortex, **N=175**, GRCh38. This is one adult bulk-brain context, not all brain tissues/cell types. Unique UCSC GRCh37-to-GRCh38 lifts, exact alleles and position joins leave **118** gene-region pairs with shared variants. Collapse rsID aliases; do not use only significant eQTLs. GWAS variants missing from QTL data cannot enter coloc. Reference ancestry is European; GTEx's tissue dataset is not demonstrated to be an exclusively European QTL subset here.
5. **Shared signals:** single-causal-variant Wakefield ABFs/coloc H0 to H4 from supplied beta/SE. H0=neither association, H1=CP only, H2=QTL only, H3=different variants, H4=shared variant. Fixed `p1=p2=1e-4`; `p12=1e-6,1e-5,1e-4`. Primary effect prior SD=0.15 trait SD, CP SD=1 (standardized phenotype); QTL SD estimated by the usual no-intercept `2*N*MAF*(1-MAF)` versus `1/SE²` regression. Report 0.10/0.20 effect-SD sensitivities and an exploratory lead +/-250 kb shared subset alongside the original gene-cis shared region. These choices are assumptions, not criteria for assigning genes. Windowing is **not** conditional/multiple-signal fine-mapping. Supplied rounded beta/SE and trait-scale estimation add uncertainty.
6. **Context, kept separate:** continuous Unknome 18 March 2026 scores/ranks from the existing uniquely HGNC-mapped protein join; Pharos 4.0 TDL independently joined through unique HGNC Entrez IDs; existing ledger PubMed/Savage/Genebass values, preserving `NA`. Missing ledger PubMed/rare values are not zero. HPA **25.1**, Ensembl 109 consensus tissue RNA locates adult expression, not causal timing. Its consensus includes GTEx, so HPA and GTEx cannot be counted as independent expression support. No gene-percentile or score-count cutoff defines a dark hit. Pharos itself labels **38** associated genes Tdark; only **three** are in the pilot: CDHR4, C3orf62 and CIMIP7.
7. **Bias:** report length/SNP-density association correlations, gene/identifier/knownness/Pharos/HPA coverage, and fixed length/density-quintile matched comparisons stratified by expression coverage; add expression-level quintile sensitivity. No p-value on reused matched controls is presented as replication. Among **374** matched scored associations, knownness is on average **0.94** units higher than matched other covered genes; with expression-level matching, **0.70** higher. This does not demonstrate unexplained-gene enrichment or remove ascertainment bias. Correlations of gene evidence (`-log10 p_gene`) with log length and density are **-0.065** and **-0.166**; these reflect a conservative procedure and this dataset, not absence of bias. HPA covers 17,904/19,430 genes, Unknome 17,401, Pharos 17,615; 1,262 lack a unique current HGNC mapping.
8. **Perturbations:** inspect Tian 2019/GSE124703 metadata, relevant main-article screen/method passages and the small neuronal guide-sequence file. Its H1 screen targets 2,325 kinase/druggable-genome genes, an annotation-biased subset; readouts are induced-neuron survival, morphology and transcription, not cognitive performance. The primary/validation XLSX requests return **HTTP 200 HTML challenges**, not usable tables. The sequence-only map has no target-gene identifiers. Therefore **per-gene coverage for all 199 pilot alternatives is not established**; no missing gene is called unscreened or a neuronal null. No full expression matrix was downloaded and no K562 result was substituted.

## Where resolution ends

| Hypothesis | Observed evidence | Why it is not a causal dark-gene assignment |
|---|---|---|
| CDHR4 (Tdark; Unknome 1.0) | Body lead r²=0.972 to R001 lead; HPA brain maximum 1.6 nTPM | Same highly correlated signal reaches other genes; no aligned DLPFC QTL for CDHR4. Low knowledge cannot decide the locus. |
| C3orf62 (Tdark; 0.5) | Body lead r²=0.099; primary H4=0.032, H3=0.458 | Could reflect another signal in the merged region. Across all documented sensitivities H4=0.002 to 0.421; no multi-signal conditioning or target-specific functional evidence. |
| CIMIP7 (Tdark; 0.0) | Gene-body association; measured HPA brain maximum 0 | Body lead is palindromic/unoriented; no aligned DLPFC QTL. Zero bulk RNA here is not universal absence or developmental proof. |
| RNF123 (Tbio; 5.4) | Body lead r²=0.964; primary H4=0.924, H3=0.075; adult RNA | A stronger shared-signal hypothesis, but not Tdark or exclusive. H4 spans 0.494 to 0.992 under priors/windows/effect scales. Multiple causal signals, co-regulation and variant coverage remain unresolved. |
| POU3F2 (Tbio; 9.8) | Body association in R002; primary H4=0.111 | Body lead r²≈0.000026 to region lead. Region membership/body association cannot identify mediation of that lead; MIR2113 and other alternatives remain. |
| SLC39A8 (Tbio; 20.9) | R003 lead rs13107325 is a VEP missense A391T coding hypothesis; BANK1 body lead r²=0.512 | A coding localization control, not unexplained biology. No exclusive mediation, adult-brain site, expression mechanism or beneficial perturbation direction follows. |

Primary H4 values in this table use the original gene-cis shared region, effect-SD 0.15 and p12=1e-5. Ranges include every documented sensitivity, not a selected favorable result. Coloc posteriors computed on different gene-specific observed subsets are not a common-scale gene-causality league table. R001 spans 2.9 Mb and clearly need not have one signal. Even a high H4 connects a variant to expression and CP under a model; it does not show that expression mediates CP.

## Files

- `gene-associations.tsv` (ignored, regenerated by the command above): every autosomal protein-coding gene, including uncovered/unscored genes, raw/conservative gene p-values and separate knownness.
- `regions.tsv`, `locus-alternatives.tsv`: all physical regions and all overlapping gene alternatives, including untested noncoding genes.
- `ranked-evidence.tsv`: all 406 associations ranked **only by genomic gene-test p**, with alternatives, knownness provenance, adult/developmental caveats, dependencies and specific disconfirming observations. `pilot-evidence.tsv` is the 51 associated pilot genes, not a new dark-gene selection. Outside-pilot LD/QTL/perturbation remains explicitly unassessed.
- `pilot-gwas.tsv`, `pilot-lead-ld.tsv`, `gene-ld-alternatives.tsv`, `ld-harmonization.tsv`, `liftover-audit.tsv`: pilot evidence and unresolved mappings.
- `coloc-sensitivity.tsv`, `qtl-gene-coverage.tsv`, `qtl-*json`: all shared-signal sensitivities, coverage and actual range access. `qtl-access-history.json` retains the first parser failure and subsequent successful accesses.
- `gene-context.tsv`, `bias-*.tsv`, `bias-summary.json`: context and matched descriptive bias audit.
- `lead-variant-consequences.tsv`: all VEP transcript/allele consequences for the three leads, not just the desired gene; coding hypotheses use only exact GWAS-compatible allele pairs. rs13107325's alternative A391S annotation is retained but does not describe Lee's C/T variant.
- `perturbation-coverage.tsv`, `perturbation-access.tsv`, `perturbation-summary.json`: per-pilot-gene unavailable coverage and actual access behavior.
- `input-provenance.tsv`, `fetch-manifest.json`, `access-inventory.tsv`, `observed-access-notes.md`: stored provenance, source hashes and access scope. Fetching rewrites the manifests. Source text excerpts are regenerated into ignored `source-method-excerpts.txt`.

## Build, terms and overlap

The original `GWAS_CP_all.txt` has GRCh37 positions. Catalog's formatted filename explicitly says `build37`; its separately **harmonized** file/YAML says GRCh38. That YAML is **not** used as the original file's build. The archived index/readme, GENCODE v19 and the 15,987 pilot reference position matches support this distinction. Only the QTL join lifts coordinates; no GRCh38 Genebass coordinates are joined to GRCh37 positions.

Lee's methods (locally extracted into `source-method-excerpts.txt`) identify UKB **222,543** plus COGENT **35,298**, standardized CP, sample-size-weighted meta-analysis and LD-score intercept adjustment. This is direct cognitive performance, unlike EA3, math/education proxies or MTAG. Savage body/FUMA/MAGMA results and Genebass come from the existing overlapping-evidence ledger; cohort independence is not established and they are **not replication**. Multiple mappings of the same Lee signal are not independent experiments. The original strict common/rare intersection and separate EA proxy files are unchanged; no KDM5B/NACC1 EA proxy is promoted into this dossier.
